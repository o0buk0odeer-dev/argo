1. 位置づけ

ARGO は、作成者（おぶこー）が自分の動画制作のために作り、自分のパソコンで動かしている個人用のソフトウェアです。一般に配布・提供しているサービスではありません。

2. 利用できる人

利用者は作成者本人に限られます。第三者への提供、譲渡、再配布は行いません。

3. できること

ARGO は、作成者本人が所有する YouTube チャンネルおよびニコニコ動画の公開情報と分析値を取得し、手元に記録して振り返るために使います。Google の API に対しては読み取りのみを行い、動画の投稿・編集・削除は行いません。

4. 禁止事項

作成者は ARGO を次の目的で使用しません。

  • 他者のアカウントへのアクセス

  • Google および各サービスの利用規約に反する行為
  • 各サービスへ過度な負荷をかける取得

5. 外部サービスの規約

ARGO の利用にあたっては、YouTube の利用規約および YouTube API サービスの利用規約に従います。

作成者は、予告なく ARGO の内容を変更し、または利用を終了することがあります。本規約を変更した場合は、このページの最終更新日を改めます。
