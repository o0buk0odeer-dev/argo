ARGO

ホームプライバシーポリシー利用規約

ARGO は、個人の動画投稿者が自分自身の動画の成績を記録して振り返るために作った、手元のパソコンで動くソフトウェアです。一般に配布しているものではなく、作成者本人だけが使っています。

何をするソフトウェアか

  • 作成者本人が所有する YouTube チャンネルの、公開値と分析値を毎日取得して保存します
  • あわせてニコニコ動画の公開値も取得します
  • 手元の動画制作フォルダの状況（台本や書き出しファイルの有無）を棚卸しします
  • 集めたものを一枚の状態レポートにまとめ、次に何を作るかの判断材料にします

使っている Google の機能

  • YouTube Data API v3
  • YouTube Analytics API
  • YouTube Reporting API

要求している権限は youtube.readonly と yt-analytics.readonly の2つだけで、どちらも読み取り専用です。動画の投稿・編集・削除は行いません。

動く場所

作成者のパソコンの中だけで動きます。サーバーは持っておらず、取得したデータを外部へ送る先もありません。詳しくはプライバシーポリシーをご覧ください。
