ホームプライバシーポリシー利用規約

最終更新: 2026年9月21日

ARGO は、作成者本人のパソコンの中だけで動くソフトウェアです。作成者以外の利用者はおらず、第三者の個人情報を取り扱うことはありません。

1. YouTube から取得する情報

Google の API を通じて、作成者本人が所有する YouTube チャンネルについて次を取得します。

  • 動画の基本情報（題名、公開日、長さ、説明文、タグ）
  • 公開されている数値（再生数、高評価数、コメント数）
  • チャンネル所有者向けの分析値（日次の再生数、平均視聴時間、平均再生率、登録者の増減、流入元、サムネイルの表示回数とクリック率、視聴維持曲線）

取得するのは作成者自身のチャンネルの情報だけです。他の利用者のアカウントへは一切アクセスしません。視聴者個人を特定できる情報は取得しません。Google から返されるのは集計済みの数値のみです。

1-2. ニコニコ動画から取得する情報

ARGO は、作成者本人が投稿したニコニコ動画についても、誰でも閲覧できる公開情報を取得して記録します。ログインは行わず、公開されている情報のみを取得します。

  • 動画の基本情報（題名、公開日、長さ、説明文、タグ）
  • 公開されている数値（再生数、コメント数、マイリスト数）

取得するのは作成者自身が投稿した動画に限ります。視聴者個人を特定できる情報は取得しません。

あわせて、作成者自身が投稿した動画に付けられたコメントについて、動画の何秒の位置に付けられたか（再生位置）と、そのコメントが受け取ったニコられ数のみを記録します。どこで視聴者の反応が起きたかを把握し、次の動画の構成に活かすためです。

コメントの本文は保存しません。 投稿者の識別子、投稿日時、表示指定などの付随する情報も保存しません。記録するのは「何秒の位置に、何件のコメントがあったか」という数値だけです。

2. 情報の保存場所

取得した情報はすべて、作成者のパソコンのローカルディスク上のデータベースファイルに保存されます。外部のサーバーへ送信したり、クラウドへ保管したりすることはありません。

3. 情報の利用目的

作成者が自分の動画制作を振り返り、次に作るものを判断するためにのみ利用します。それ以外の目的では利用しません。

4. 第三者への提供

Google の API から取得した情報を、第三者へ提供・販売・共有することは一切ありません。広告配信にも利用しません。

なお ARGO には、インターネット上で公開されている動画やニュースの中から参考になりそうなものを選り分ける機能があり、この選り分けの判定のみ外部の AI サービス（Vercel AI Gateway）を利用します。ここへ送るのは誰でも閲覧できる公開情報（公開されている動画の題名、説明文の一部、投稿者名、URL、公開されている再生数など）だけです。Google の API から取得した情報、チャンネル所有者向けの分析値、認証情報は送信しません。

5. 認証情報の取り扱い

Google の認可トークンは作成者のパソコン内のファイルにのみ保存され、外部へ送信されることはありません。保存先はソースコードの管理対象から除外しています。

6. Google のユーザーデータに関する方針の遵守

ARGO による Google API からの情報の利用および他アプリへの移転は、Google API サービスのユーザーデータに関するポリシー（限定的な使用に関する要件を含む）に準拠します。

7. 保存期間と削除

データはローカルのデータベースファイルに蓄積されます。作成者はいつでもこのファイルを削除でき、削除すれば保存された情報は失われます。

8. アクセス権の取り消し

ARGO に与えた Google アカウントへのアクセス権は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

9. 本ポリシーの変更

内容を変更した場合は、このページの最終更新日を改めます。
